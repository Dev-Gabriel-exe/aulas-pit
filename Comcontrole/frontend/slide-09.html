LAB: dashboard de métricas de classificação com dados de IA
Atividade LAB

Construir um dashboard React que exibe métricas de um modelo de classificação (accuracy, precision, recall por época e por classe) usando Recharts — com dados reais ou simulados de um modelo de sentimento.

O que você vai usar hoje
  • recharts — gráficos declarativos em React com SVG
  • chart.js + react-chartjs-2 — alternativa imperativa com Canvas
  • Dados de treinamento de modelo (accuracy, loss, confusion matrix)
  • useState + useEffect para simular dados chegando em tempo real
  • CSS Grid para layout de dashboard responsivo
Onde estamos
  • ✅ Sem. 7 — Streaming: SSE, ReadableStream
  • ✅ Sem. 8 — Exibindo resultados: markdown, highlight
  • ▶ Sem. 9 — Visualização de dados com Chart.js e Recharts

  • Recharts é declarativo como o React — componibilidade ao invés de configuração
  • Saber escolher o tipo de gráfico certo é habilidade de produto, não só de código

Quando visualizar — e qual biblioteca escolher
A escolha certa de gráfico comunica, a errada confunde

Antes de escrever uma linha de código, a pergunta certa é: o que o usuário precisa entender com esse dado? Cada tipo de gráfico responde a uma pergunta diferente. Usar o tipo errado é pior do que usar uma tabela.

Pergunta que o dado respondeTipo de gráficoExemplo em IA
Como X muda ao longo do tempo?Linha (LineChart)Accuracy e loss por época de treinamento
Como X se compara a Y e Z?Barras (BarChart)Precision por classe, score de modelos diferentes
Qual a proporção de cada parte?Pizza / Donut (PieChart)Distribuição de sentimentos, classes previstas
Existe correlação entre X e Y?Dispersão (ScatterChart)Confiança do modelo vs erro real
Onde os valores se concentram?Área (AreaChart)Distribuição de probabilidade de predição
Regra de ouro: se você tem menos de 5 números, use uma tabela. Se você tem tendência temporal, use linha. Se você tem comparação entre categorias, use barras. Pizza só para até 5 fatias e quando a proporção é o que importa — nunca para comparar valores próximos.

Instalação e anatomia do Recharts

O Recharts segue o mesmo modelo mental do React: tudo é um componente. Um gráfico é composto de camadas — o container, os eixos, as séries de dados e elementos auxiliares como tooltips e legenda. Você os compõe como JSX.

Terminal
npm install recharts
Anatomia de qualquer gráfico Recharts: (1) Container responsivo ResponsiveContainer que se ajusta ao pai — sempre o mais externo. (2) Tipo do gráfico (LineChart, BarChart, etc.) com a prop data. (3) Eixos: XAxis e YAxis. (4) Séries: Line, Bar com dataKey apontando para o campo do objeto de dados. (5) Opcionais: Tooltip, Legend, CartesianGrid.
LineChart — accuracy e loss por época
React — GraficoTreinamento.jsx
import {
  LineChart, Line, XAxis, YAxis, CartesianGrid,
  Tooltip, Legend, ResponsiveContainer
} from 'recharts';

// Dados: array de objetos com um campo por série
const dadosTreinamento = [
  { epoca: 1,  accuracy: 0.52, loss: 0.88, val_accuracy: 0.49 },
  { epoca: 3,  accuracy: 0.71, loss: 0.62, val_accuracy: 0.67 },
  { epoca: 5,  accuracy: 0.82, loss: 0.44, val_accuracy: 0.78 },
  { epoca: 8,  accuracy: 0.89, loss: 0.28, val_accuracy: 0.85 },
  { epoca: 12, accuracy: 0.93, loss: 0.18, val_accuracy: 0.88 },
  { epoca: 15, accuracy: 0.96, loss: 0.11, val_accuracy: 0.87 },
];

export default function GraficoTreinamento() {
  return (
    <ResponsiveContainer width="100%" height={280}>
      <LineChart data={dadosTreinamento} margin={{ top: 5, right: 20, left: 0, bottom: 5 }}>

        <CartesianGrid strokeDasharray="3 3" stroke="rgba(255,255,255,.06)" />

        <XAxis
          dataKey="epoca"
          label={{ value: 'Época', position: 'insideBottom', offset: -2 }}
          stroke="rgba(255,255,255,.3)"
          tick={{ fill: 'rgba(255,255,255,.4)', fontSize: 12 }}
        />

        <YAxis
          domain={[0, 1]}
          tickFormatter={(v) => v.toFixed(1)}
          stroke="rgba(255,255,255,.3)"
          tick={{ fill: 'rgba(255,255,255,.4)', fontSize: 12 }}
        />

        <Tooltip
          contentStyle={{ background: '#1a1500', border: '1px solid rgba(251,191,36,.3)', borderRadius: '8px' }}
          labelStyle={{ color: '#fbbf24' }}
          formatter={(value, name) => [value.toFixed(3), name]}
        />

        <Legend wrapperStyle={{ color: 'rgba(255,255,255,.6)', fontSize: '12px' }} />

        <Line type="monotone" dataKey="accuracy"    stroke="#fbbf24" strokeWidth={2.5} dot={{ r: 4 }} />
        <Line type="monotone" dataKey="val_accuracy" stroke="#38bdf8" strokeWidth={2}   strokeDasharray="5 3" dot={{ r: 3 }} />
        <Line type="monotone" dataKey="loss"         stroke="#f87171" strokeWidth={2}   dot={{ r: 3 }} />

      </LineChart>
    </ResponsiveContainer>
  );
}
Detectando overfitting no gráfico: quando a linha de accuracy (treino) continua subindo mas val_accuracy (validação) começa a cair ou estagna, o modelo está memorizando o treino. Ver isso em um gráfico de linha é instantâneo — em tabela de números, você precisaria comparar linha por linha.
BarChart — comparando métricas por classe
React — GraficoMetricasPorClasse.jsx
import {
  BarChart, Bar, XAxis, YAxis, CartesianGrid,
  Tooltip, Legend, ResponsiveContainer, Cell
} from 'recharts';

const dadosClasses = [
  { classe: 'Positivo', precision: 0.92, recall: 0.89, f1: 0.90 },
  { classe: 'Negativo', precision: 0.87, recall: 0.85, f1: 0.86 },
  { classe: 'Neutro',   precision: 0.74, recall: 0.79, f1: 0.76 },
  { classe: 'Misto',    precision: 0.61, recall: 0.55, f1: 0.58 },
];

// Tooltip customizado
function TooltipCustom({ active, payload, label }) {
  if (!active || !payload?.length) return null;
  return (
    <div style={{ background: '#1a1500', border: '1px solid rgba(251,191,36,.3)', borderRadius: '8px', padding: '.75rem 1rem' }}>
      <p style={{ color: '#fbbf24', fontWeight: 700, marginBottom: '.4rem' }}>{label}</p>
      {payload.map(p => (
        <p key={p.dataKey} style={{ color: p.color, fontSize: '.82rem' }}>
          {p.name}: {p.value.toFixed(2)}
        </p>
      ))}
    </div>
  );
}

export default function GraficoMetricas() {
  return (
    <ResponsiveContainer width="100%" height={280}>
      <BarChart data={dadosClasses} margin={{ top: 5, right: 20, left: 0, bottom: 5 }}>
        <CartesianGrid strokeDasharray="3 3" stroke="rgba(255,255,255,.06)" />
        <XAxis dataKey="classe" tick={{ fill: 'rgba(255,255,255,.5)', fontSize: 12 }} />
        <YAxis domain={[0, 1]} tickFormatter={(v) => v.toFixed(1)} tick={{ fill: 'rgba(255,255,255,.4)', fontSize: 12 }} />
        <Tooltip content=<TooltipCustom /> />
        <Legend wrapperStyle={{ color: 'rgba(255,255,255,.6)', fontSize: '12px' }} />
        <Bar dataKey="precision" fill="#fbbf24" radius={[4,4,0,0]} />
        <Bar dataKey="recall"    fill="#38bdf8" radius={[4,4,0,0]} />
        <Bar dataKey="f1"        fill="#4ade80" radius={[4,4,0,0]} />
      </BarChart>
    </ResponsiveContainer>
  );
}
PieChart — distribuição de sentimentos
React — GraficoDistribuicao.jsx
import { PieChart, Pie, Cell, Tooltip, Legend, ResponsiveContainer } from 'recharts';

const distribuicao = [
  { nome: 'Positivo', valor: 52, cor: '#4ade80' },
  { nome: 'Negativo', valor: 28, cor: '#f87171' },
  { nome: 'Neutro',   valor: 20, cor: '#fbbf24' },
];

// Rótulo customizado no segmento
const RotuloCustom = ({ cx, cy, midAngle, innerRadius, outerRadius, percent }) => {
  const RADIAN = Math.PI / 180;
  const r = innerRadius + (outerRadius - innerRadius) * 0.5;
  const x = cx + r * Math.cos(-midAngle * RADIAN);
  const y = cy + r * Math.sin(-midAngle * RADIAN);
  return (
    <text x={x} y={y} fill="white" textAnchor="middle" dominantBaseline="central" fontSize={13} fontWeight="700">
      {`${(percent * 100).toFixed(0)}%`}
    </text>
  );
};

export default function GraficoDistribuicao() {
  return (
    <ResponsiveContainer width="100%" height={260}>
      <PieChart>
        <Pie
          data={distribuicao}
          dataKey="valor"
          nameKey="nome"
          cx="50%" cy="50%"
          innerRadius={55}   // 0 = pizza, >0 = donut
          outerRadius={100}
          labelLine={false}
          label={RotuloCustom}
        >
          {distribuicao.map((entrada) => (
            <Cell key={entrada.nome} fill={entrada.cor} />
          ))}
        </Pie>
        <Tooltip
          formatter={(value, name) => [`${value}%`, name]}
          contentStyle={{ background: '#1a1500', border: '1px solid rgba(251,191,36,.3)', borderRadius: '8px' }}
        />
        <Legend wrapperStyle={{ color: 'rgba(255,255,255,.6)', fontSize: '12px' }} />
      </PieChart>
    </ResponsiveContainer>
  );
}
🙋 No Recharts, o que a prop dataKey de um componente Line ou Bar indica?
A
A cor da série no gráfico — cada dataKey tem uma cor automática diferente
B
O campo do eixo X — qual propriedade do objeto de dados é usada como categoria
C
Qual campo do objeto de dados essa série vai plotar — o nome da propriedade numérica que alimenta a série
D
O índice do array de dados que essa série representa

LAB — Dashboard de métricas de um modelo de sentimento
Objetivo: construir um dashboard React com três gráficos Recharts mostrando métricas de um modelo de análise de sentimento — curva de treinamento (linha), métricas por classe (barras) e distribuição de predições (donut) — com cards de KPI no topo e layout responsivo em grid.
Passo a passo do LAB
1
Criar o projeto e instalar
Novo projeto React ou use o existente. npm install recharts. Crie um arquivo dadosModelo.js com os três conjuntos de dados das Aulas 1 e 2 — centralize aqui para reusar nos componentes.
2
Criar os três componentes de gráfico
Um arquivo por gráfico: GraficoTreinamento.jsx, GraficoMetricas.jsx, GraficoDistribuicao.jsx. Cada componente recebe dados como prop — não hardcode dentro do gráfico.
3
Montar o Dashboard com cards KPI
No Dashboard.jsx: quatro cards de KPI no topo (accuracy, precision, recall, F1 médios), abaixo o GraficoTreinamento em largura total, depois GraficoMetricas e GraficoDistribuicao lado a lado em grid 2 colunas. Use o código do componente abaixo.
4
Adicionar simulação de dados em tempo real
Use useState para guardar as épocas exibidas e useEffect com setInterval de 800ms para adicionar uma época por vez ao array. O gráfico de linha cresce em tempo real simulando um treinamento ao vivo.
5
Tornar responsivo
ResponsiveContainer já cuida da largura. Para o grid de 2 colunas virar 1 coluna em mobile, adicione um media query simples ou use CSS Grid com grid-template-columns: repeat(auto-fit, minmax(320px, 1fr)).
React — Dashboard.jsx completo
import { useState, useEffect } from 'react';
import GraficoTreinamento from './GraficoTreinamento';
import GraficoMetricas from './GraficoMetricas';
import GraficoDistribuicao from './GraficoDistribuicao';
import { todasEpocas, dadosClasses, distribuicao } from './dadosModelo';
import './Dashboard.css';

function CardKPI({ label, valor, cor }) {
  return (
    <div className="kpi-card">
      <span className="kpi-label">{label}</span>
      <span className="kpi-valor" style={{ color: cor }}>{valor}</span>
    </div>
  );
}

export default function Dashboard() {
  const [epocasVisiveis, setEpocasVisiveis] = useState([todasEpocas[0]]);
  const [simulando, setSimulando] = useState(true);

  // Simula treinamento em tempo real — adiciona uma época a cada 800ms
  useEffect(() => {
    if (!simulando) return;
    const id = setInterval(() => {
      setEpocasVisiveis(prev => {
        if (prev.length >= todasEpocas.length) {
          setSimulando(false);
          clearInterval(id);
          return prev;
        }
        return [...prev, todasEpocas[prev.length]];
      });
    }, 800);
    return () => clearInterval(id);
  }, [simulando]);

  const ultimaEpoca = epocasVisiveis[epocasVisiveis.length - 1];

  return (
    <div className="dashboard">
      <header className="dash-header">
        <h1>Dashboard — Modelo de Sentimento</h1>
        <span className={`status ${simulando ? 'treinando' : 'concluido'}`}>
          {simulando ? '⏳ Treinando...' : '✅ Treinamento concluído'}
        </span>
      </header>

      <div className="kpi-row">
        <CardKPI label="Accuracy"  valor={(ultimaEpoca.accuracy * 100).toFixed(1) + '%'}  cor="#fbbf24" />
        <CardKPI label="Val Acc"   valor={(ultimaEpoca.val_accuracy * 100).toFixed(1) + '%'} cor="#38bdf8" />
        <CardKPI label="Loss"      valor={ultimaEpoca.loss.toFixed(3)}                        cor="#f87171" />
        <CardKPI label="Época"     valor={`${epocasVisiveis.length} / ${todasEpocas.length}`}   cor="#a78bfa" />
      </div>

      <div className="chart-full">
        <h2>Curva de Treinamento</h2>
        <GraficoTreinamento dados={epocasVisiveis} />
      </div>

      <div className="chart-grid">
        <div>
          <h2>Métricas por Classe</h2>
          <GraficoMetricas dados={dadosClasses} />
        </div>
        <div>
          <h2>Distribuição de Predições</h2>
          <GraficoDistribuicao dados={distribuicao} />
        </div>
      </div>
    </div>
  );
}

Exercício 02 — Tooltip personalizado com delta

Melhore o tooltip do GraficoTreinamento para mostrar, além dos valores atuais, a variação em relação à época anterior (delta). Por exemplo: "Accuracy: 0.89 (+0.07)". Para isso, o tooltip recebe o índice do ponto atual via payload[0].index — use-o para acessar o item anterior no array de dados.

LAB
React — TooltipComDelta.jsx
function TooltipComDelta({ active, payload, label, dados }) {
  if (!active || !payload?.length) return null;
  const idx = dados.findIndex(d => d.epoca === label);
  const anterior = idx > 0 ? dados[idx - 1] : null;

  return (
    <div style={{ background: '#1a1500', border: '1px solid rgba(251,191,36,.3)', borderRadius: '8px', padding: '.75rem 1rem' }}>
      <p style={{ color: '#fbbf24', fontWeight: 700, marginBottom: '.4rem' }}>Época {label}</p>
      {payload.map(p => {
        const delta = anterior ? p.value - anterior[p.dataKey] : 0;
        const sinal = delta >= 0 ? '+' : '';
        return (
          <p key={p.dataKey} style={{ color: p.color, fontSize: '.82rem' }}>
            {p.name}: {p.value.toFixed(3)}
            {anterior && <span style={{ color: delta >= 0 ? '#4ade80' : '#f87171', fontSize: '.75rem', marginLeft: '.35rem' }}>({sinal}{delta.toFixed(3)})</span>}
          </p>
        );
      })}
    </div>
  );
}

Exercício 04 — Desafio: matriz de confusão como heatmap

Implemente uma matriz de confusão 4×4 (Positivo, Negativo, Neutro, Misto) como um heatmap usando apenas SVG e React — sem biblioteca adicional. Cada célula tem cor interpolada entre branco (valor 0) e verde/âmbar (valor máximo). Exiba o número de predições em cada célula. Dados sugeridos: diagonal principal com valores altos (verdadeiros positivos), células fora da diagonal com valores baixos (erros).

Desafio
React — MatrizConfusao.jsx
const classes = ['Pos', 'Neg', 'Neu', 'Mix'];
const matriz = [
  [210, 12,  8,  5],
  [15, 195, 10,  4],
  [9,  11, 168, 18],
  [6,   7,  22, 130],
];
const maxVal = Math.max(...matriz.flat());

function corCelula(valor) {
  const t = valor / maxVal;
  // interpola de rgba(255,255,255,.04) para #fbbf24
  const r = Math.round(15 + t * (251 - 15));
  const g = Math.round(15 + t * (191 - 15));
  const b = Math.round(20 + t * (36 - 20));
  return `rgb(${r},${g},${b})`;
}

export default function MatrizConfusao() {
  const size = 58, padding = 36;
  const total = size * classes.length + padding;
  return (
    <svg viewBox={`0 0 ${total + padding} ${total + padding}`} width="100%">
      {/* Labels eixo X (predito) */}
      {classes.map((c, j) => (
        <text key={j} x={padding + j * size + size / 2} y={18}
          textAnchor="middle" fill="rgba(255,255,255,.4)" fontSize={11}>{c}</text>
      ))}
      {matriz.map((linha, i) =>
        linha.map((val, j) => (
          <g key={`${i}-${j}`}>
            <rect
              x={padding + j * size} y={padding + i * size}
              width={size - 2} height={size - 2}
              fill={corCelula(val)} rx={4}
            />
            <text
              x={padding + j * size + size / 2}
              y={padding + i * size + size / 2 + 5}
              textAnchor="middle"
              fill={val / maxVal > 0.5 ? '#0f0d1a' : 'rgba(255,255,255,.7)'}
              fontSize={13} fontWeight="700"
            >{val}</text>
          </g>
        ))
      )}
    </svg>
  );
}
